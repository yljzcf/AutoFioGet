写入身份
第一次授权前，先把这个地址加到应用的「安全设置 → 重定向 URL」（打开安全设置）：
应用需要的权限（第一次配置看这里）
  1. 给应用开通用户身份权限：打开权限申请页（填好 App ID 后生成），勾选后提交。需要的权限：base:table:read base:record:read base:record:create base:record:update docs:document.media:upload wiki:node:read offline_access。然后在「版本管理与发布」创建并发布新版本。
  2. 把上面的重定向 URL 加到应用的「安全设置 → 重定向 URL」。插件文件夹换了位置，这个地址会变，要重新加。
  3. 点「用 Lark 账号授权」，在弹出的窗口里登录。有多个组织时，选应用所在组织的那个账号。
  4. 让多维表格的所有者把这个账号加为协作者（可编辑）。表格在别的组织时，那个组织需要允许对外分享。
  5. 回来点「测试连接」，能看到表里的记录数就说明配好了。之后每次同步会自动续期授权，连续 7 天没有同步才需要重新授权。
  1. 给应用开通权限：打开权限申请页（填好 App ID 和多维表格链接后生成），勾选后提交。需要的权限：base:table:read base:record:read base:record:create base:record:update docs:document.media:upload。
  2. 在开发者后台「版本管理与发布」创建一个新版本并发布（权限要发布后才生效；企业管理员可能需要审核）。
  3. 把应用加为这个多维表格的协作者（可编辑）：多维表格右上角「…」→「更多」→「添加文档应用」，搜索应用名。
  4. 回来点「测试连接」，能看到表里的记录数就说明配好了。

飞书那边怎么配置？
  1. 在多维表格里建一张数据表，字段见 README（分享名称、文件夹、视频、编号、类型、回复对象、开始时间码、结束时间码、开始秒数、作者、内容、创建时间、编辑时间、已完成、视频链接、首次抓取时间、批注ID）。
  2. 左下角「新建 → 工作流」，触发条件选「接收到 webhook 时」，复制 webhook 地址填到上面并保存。
  3. 在触发器的「输出设置」里选「通过发送请求设置」，回到这里点「发送测试数据」，再回飞书点「生成」。
  4. 添加「循环」节点：需要依次处理的数据选 webhook 返回值里的 items，最大循环次数按你的飞书版本填（和上面的「每批条数」一致）。
  5. 在循环里添加「新增记录」，选上面那张表，每个字段引用「当前循环数据」的同名字段。保存并启用。
  6. 存量批注很多、又是免费版时：先在弹窗里「导出全部 CSV」导入多维表格，再点「全部标记为已同步」，之后只推新增的。
